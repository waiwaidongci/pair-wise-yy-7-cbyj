# 古船模型帆索复核台

古船模型帆索松紧的立项—调整—复核工作台。运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`。

## 规则

- **一型一单**：每个模型同时只允许存在一项未闭环（非「已闭环」）索具任务；已闭环归档后才能再立项。
- **顺序推进，不能跳步**：任务阶段固定为 `待检查 → 调整中 → 待复核 → 已闭环`，服务端校验非法流转。
- **修订唯一**：调整中提交松紧只会生成一条待复核修订，索具位置等锁定参数不变；任务停在待复核期间重复提交，沿用首次修订（仅记录重复次数与历史，不产生新值）。
- **复核才换值**：复核通过前原值继续有效；通过后才以修订值替换并把旧值归档到任务历史；驳回则修订作废、原值继续有效，任务回到调整中。
- **参数变更触发重核**：模型比例或交付日期变更后，未闭环任务回到待检查、按新参数重核；待复核修订同时作废；旧结论失效，但全部过程保留在任务历史与模型时间线可查。已闭环任务不受影响。
- **一致状态**：列表、状态筛选、搜索和刷新都从同一份服务端数据渲染；模型卡片状态由未闭环任务派生（待命 / 待检查 / 调整中 / 待复核）。
